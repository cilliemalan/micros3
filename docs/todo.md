# TODO

## Web UI

A browser console for the emulator, to browse and administer buckets and objects. Its design is in [UI.md](UI.md), which this list implements. It runs on its own port in the same process as the S3 API, is compiled into the one static executable, and has a React frontend built with the Vercel UI SDK (`@ui-sdk/react`, `@ui-sdk/core`, beta). Its backend is a JSON API under `/api/` that calls the store directly.

Decisions from the owner. UI.md records them, and design.md gets them in U1:

- [x] **UI1. Own port.** Default `3924`, set by `--ui-port <n>` or `MICROS3_UI_PORT`. It must differ from the S3 port. The UI is not served on the S3 port.
- [x] **UI2. No security, own JSON API.** No authentication, no SigV4 in the browser. The API is under `/api/` on the UI port and calls the store directly.
- [x] **UI3. Plain HTTP.** TLS and reverse proxies are the user's concern.
- [x] **UI4. Embedded at build time.** The frontend is built and its files are compiled into the executable.
- [x] **UI5. Always on.** To run without the UI, do not publish its port in Docker.

Open, from UI.md. Each needs an answer before the step it blocks:

- [ ] **O1. Origin and Host checks on the API (recommended).** Reject `POST`, `PUT` and `DELETE` on `/api/` when `Origin` is present and is not the UI's own origin. Reject any request whose `Host` is not the UI's own address. This blocks other web pages and DNS rebinding, and it is not authentication. Blocks U3 and U6. (UI.md, Open 1.)
- [ ] **O2. Metadata edit in place.** Edit headers on the object row, without copying the blob, so ETag and last-modified stay the same. This differs from S3, which copies the object. Blocks U8. (UI.md, Open 2.)
- [ ] **O3. Node.js at build time.** The frontend build needs Node and npm, so a C++ build needs them too. Alternative: commit the built `ui/dist`. Blocks U5. (UI.md, Open 3.)
